Como a seção Projects vira um carrossel

Este guia disseca o HTML da seção de projetos do portfólio e explica, peça por peça, a estrutura que a biblioteca Swiper.js exige para transformar uma lista simples em um carrossel navegável — com setas, paginação e slides.

Hierarquia exigida pelo Swiper
.swiper Contêiner raiz — delimita a "janela" visível do carrossel
.swiper-wrapper Trilho que desliza — agrupa e move todos os slides
.swiper-slide Projeto GitHub
.swiper-slide próximo projeto…
.swiper-slide próximo projeto…
.swiper-button-prev / -next Setas de navegação — irmãs do wrapper, não filhas
.swiper-pagination Bolinhas indicadoras da posição atual

02 · referência rápida

        
Função de cada classe Swiper

        
Toda essa nomenclatura não é estética: são os hooks que o JavaScript do Swiper procura no DOM ao ser inicializado.

      


      

        

          
            
Classe / elementoOnde ficaO que faz

          
          
            

              .swiperraiz
              No projeto, a <div class="swiper projects-swiper"> que envolve tudo.
              Contêiner principal. É o elemento passado ao construtor new Swiper(). Define o recorte (overflow) por onde os slides aparecem.
            

            

              .swiper-wrapperobrigatória
              <div class="swiper-wrapper">, filha direta de .swiper.
              Trilho deslizante. O Swiper aplica transform: translate3d() nesse elemento para mover o conjunto de slides horizontalmente.
            

            

              .swiper-slideobrigatória
              Cada <div class="swiper-slide">, filha direta de .swiper-wrapper.
              Um item do carrossel. No projeto, cada slide envolve um .project-card (ícone, título, tags e botões do projeto).
            

            

              .swiper-button-next / -prevprecisa de JS
              <div class="swiper-button-next"> e -prev, irmãs de .swiper-wrapper.
              Setas de navegação. Só ficam clicáveis quando o módulo Navigation é habilitado na inicialização do JS.
            

            

              .swiper-paginationprecisa de JS
              <div class="swiper-pagination">, também irmã de .swiper-wrapper.
              Indicador de posição. O módulo Pagination injeta as bolinhas dinamicamente aqui em tempo de execução.
